**gRaku Studio** (**g** for *Game* + **楽** *Raku: Effortless & Fun*) is an accessible, web-based visual game engine designed to run seamlessly in the browser across desktop, tablets, and mobile devices.       
This repository serves as the central hub for documentation, game samples, project templates, and engine resources. The official visual editor will be hosted and accessible via a dedicated web platform (launching soon).

---                                                                   
## Features                                                           
- **Visual Scene Editor**: Drag-and-drop objects, transform gizmos, hierarchy tree, and real-time inspector.
- **Tilemap Studio**: Paint levels with brush, box fill, bucket tools, and 1-click physics colliders.
- **Animation Studio**: Spritesheet slicer, timeline tracks, and live 60 FPS preview with onion skinning.
- **SFX Synthesizer**: Generate 8-bit retro sound effects (jump, laser, coin, explosion) with a single click.
- **WASM 2D Physics**: High-performance deterministic simulation powered by Rapier2D.
- **AI Copilot & Scripting**: Natural language assistant and component-based JavaScript logic.
- **Mobile-First Touch Controls**: Built-in virtual joystick, D-pad, and action buttons for touchscreen devices.

---

## Multi-Platform Export

Export standalone games directly from the studio:
- **Web (HTML5)**: Playable .zip package for itch.io, CrazyGames, or self-hosting.
- **Progressive Web App (PWA)**: Offline installable app for mobile and desktop.
- **DroidScript (.SPK)**: Ready-to-run package for Android devices.
